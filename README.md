# 🔐 Password Generator (Tkinter)

A simple and stylish **Password Generator GUI Application** built using **Python** and **Tkinter**.  
This application allows users to generate secure passwords with customizable options like letters, numbers, and symbols.

---

## 📌 Features

- Generate strong random passwords
- Choose password length
- Include:
  - ✅ Letters
  - ✅ Numbers
  - ✅ Symbols
- Copy password to clipboard
- Simple dark-themed GUI using Tkinter

---

## 🖥️ Preview

The application window contains:

- Password length input
- Option checkboxes
- Generate button
- Password display field
- Copy-to-clipboard button

---

## 🛠️ Technologies Used

- Python 3
- Tkinter (GUI)
- Random module
- String module
